ReelLessPrivacy policy
Effective September 1, 2026

Local by design.

ReelLess does not collect, transmit, sell, or share personal information. It includes no analytics, ads, tracking pixels, remote code, accounts, or external network requests.

What is processed

On sites you enable, scripts inspect the current URL and specific local page elements and links needed to find Shorts, Reels, and other selected entry points. This happens only in your browser. If you start the optional Ultimate Lock release ritual, the reflection you type remains only in the open Settings page and is discarded when it closes or reloads. ReelLess does not transmit or store that reflection, URLs, page contents, titles, account details, messages, comments, cookies, or browsing history.

What is stored

Chrome stores your modes, section choices, schedules, pause expiry, appearance preference, Ultimate Lock state, custom entries, first-run state, an active-day count used only to delay the neutral review prompt, and a daily/all-time count. Counts contain only a local day and two numbers. No URL, title, or platform history is retained.

Site access

YouTube, Instagram, Facebook, and TikTok are included. Seven Advanced sites and custom domains request exact optional HTTPS access only after you enable them. Disabling an optional site removes access when it is no longer needed.
