Get set up

Three small steps.

01

Start with the defaults

Core protection is on. You can turn an individual site off from the popup whenever you need to.

02

Pin ReelLess

Open your browser’s Extensions menu, then pin ReelLess. The popup keeps pause controls within reach. Chrome: puzzle icon → pin. Edge: Extensions → pin. Firefox: Extensions button → pin to toolbar.

03

Add only what helps

Settings keeps schedules, extra sites, and custom pages in Advanced. Your browser asks before any optional site access is added. After granting access, refresh already-open tabs on that site.
