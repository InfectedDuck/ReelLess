# ReelLess Chrome Web Store Submission Kit

Upload `UPLOAD-THIS-reels-blocker-v2.2.1.zip` to the Chrome Web Store Developer Dashboard. It is already correctly packaged with `manifest.json` at the ZIP root.

Do not upload or ZIP this whole folder. The other folders contain separate Store listing images and reference documents used while completing the dashboard.

- `listing-assets`: screenshots and promotional images to upload in the Store Listing tab.
- `documents`: listing copy, privacy policy, security review, manual test matrix, and publishing checklist.

The public privacy and support pages are maintained in the repository's `docs` folder and should be published with GitHub Pages before the Store listing goes live.
