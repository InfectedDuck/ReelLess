Support

Let’s fix the distraction, not add friction.

For bugs or feature requests, open a public GitHub issue. Do not include private account details or private URLs.

Before reporting a blocking bug

  1. Open your browser's extensions page (chrome://extensions, edge://extensions, or about:addons) and click Reload on ReelLess.
  2. Refresh the affected social-media tab (already-open tabs need a refresh after granting access or updating).
  3. Confirm the site is enabled and protection is not paused or outside its schedule.
  4. Check the extension card and service-worker console for errors.

Useful report details

Include browser and version, desktop platform, logged-in or logged-out state, whether the link was direct or clicked in-app, expected behavior, actual behavior, and a screenshot with personal information removed. From Settings → Help you can Copy diagnostics (version, status, and site modes only — never URLs or page content).
