A blocker that keeps its distance.

ReelLess processes the current page locally. It has no account, analytics, ads, or external requests.

Permission by choice. Core sites work after installation. Extra sites ask only when you enable them.

Counts without history. ReelLess stores a local day and two numbers—never URLs, titles, or watch history.

Try it in Chrome

1 Open chrome://extensions and enable Developer mode.

2 Click Load unpacked and choose this project folder, not the ZIP.

3 Pin ReelLess, then refresh a supported site.
